unimap

A Unicode character map for the terminal · source on GitHub

Install on Debian, Ubuntu, Kali, Mint…

Add the repository and its signing key once:

curl -fsSL https://kristijanmatas.github.io/unimap/key.gpg \
  | sudo gpg --dearmor -o /usr/share/keyrings/unimap.gpg

echo "deb [signed-by=/usr/share/keyrings/unimap.gpg] https://kristijanmatas.github.io/unimap stable main" \
  | sudo tee /etc/apt/sources.list.d/unimap.list

sudo apt update
sudo apt install unimap

New versions then arrive with sudo apt upgrade. The package contains a static binary and works on any 64-bit (amd64) release.

Remove

sudo apt remove unimap
sudo rm /etc/apt/sources.list.d/unimap.list /usr/share/keyrings/unimap.gpg

Other ways to install

Download a prebuilt binary or .deb from the releases page, or build from source with make && sudo make install.
